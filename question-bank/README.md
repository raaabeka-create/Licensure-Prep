# NursePrep Question Bank

This directory contains original, structured NCLEX-RN-style practice questions, separated by subject.

## Planned subject files

1. `01_fundamentals.json` — Fundamentals of Nursing
2. `02_medical_surgical.json` — Medical-Surgical Nursing
3. `03_pharmacology.json` — Pharmacology
4. `04_maternal_newborn.json` — Maternal and Newborn Nursing
5. `05_paediatric.json` — Paediatric Nursing
6. `06_psychiatric_mental_health.json` — Psychiatric and Mental Health Nursing
7. `07_community_health.json` — Community Health Nursing
8. `08_leadership_management.json` — Nursing Leadership and Management
9. `09_ethics_legal.json` — Nursing Ethics and Legal Issues
10. `10_comprehensive_nclex.json` — Comprehensive NCLEX-RN Practice

Target: 200 reviewed questions per subject (2,000 total).

## Question record format

Each question will include a stable ID, subject, topic, difficulty, stem, four options (A–D), correct answer, concise rationale, and optional clinical metadata. Question content must be original and clinically reviewed; it must not reproduce proprietary question-bank content.

**Important:** The target count is a plan, not a claim that all questions already exist. Files will be added as question sets are authored and validated.
